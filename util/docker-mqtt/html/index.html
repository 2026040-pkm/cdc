MQTT Broker 테스트 스크립트

세 MQTT 브로커의 테스트 메시지 발행 및 retained topic 초기화 정보를 정리한 문서입니다.

브로커 연결 정보

브로커호스트 포트기본 topic상태
Mosquitto1883ot/device/fabrication/mosquitto/status확인 완료
EMQX1884ot/device/fabrication/emqx/status확인 완료
NATS MQTT1885ot/device/fabrication/nats/status확인 완료

Publish 실행

각 스크립트는 고정 장비 ID 3개를 순회하며 시간, 상태 및 측정값을 변경해 발행합니다.

sh scripts/mqtt/publish-mosquitto-status.sh
sh scripts/mqtt/publish-emqx-status.sh
sh scripts/mqtt/publish-nats-status.sh

Retained topic 초기화

기본적으로 세 브로커에서 ot/device/fabrication/#에 해당하는 retained topic을 찾아 초기화합니다.

sh scripts/mqtt/reset-broker-topics.sh

환경변수 설정 예시

DEVICE_IDS="device-a device-b device-c" \
BROKER_PORT=1884 \
TOPIC="ot/device/fabrication/custom/status" \
sh scripts/mqtt/publish-emqx-status.sh

TOPIC_FILTER="ot/device/fabrication/#" \
BROKER_PORTS="1883 1884 1885" \
sh scripts/mqtt/reset-broker-topics.sh
