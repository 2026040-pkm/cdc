    ADR-01 · rootless Podman 이 아니라 WSL Ubuntu 의 rootful docker 로 올린다

    배경
    SAP HANA 는 컨테이너에 kernel.shmmax · shmmni · shmall · msgmni · sem 을 넘겨야 합니다. 이 sysctl 은 네임스페이스 값이라 docker --sysctl 로 줄 수 있지만 rootless Podman 에서는 거부됩니다.
    결정
    이미 실행 중이던 Ubuntu 22.04 배포판의 docker 27.3.1(systemd 서비스, 사용자 black 이 docker 그룹)로 기동합니다. 모든 명령은 wsl -d ubuntu-22.04 -- 로 감쌉니다.
    대가
    Podman 의 기존 컨테이너(mqtt · tsdb · kafka 등)와 다른 데몬에 있어 podman ps 에는 a4h 가 보이지 않습니다. WSL 메모리 한도는 두 배포판이 함께 씁니다.
    재검토
    Docker Desktop 을 설치하거나 Podman 을 rootful 로 전환하면 이 결정을 다시 봅니다. 그 전까지 a4h 를 옮기지 않습니다(컨테이너를 다시 만들면 SAP 데이터가 사라짐).

    4 · 기동 감시

    sap-wait.sh — Windows 임시 폴더에 두고 WSL 에서 실행 (인라인 sh -c 는 wsl 을 거치며 $ 변수가 깨져 스크립트 파일로 바꿨음)
    #!/bin/sh
i=0
while [ "$i" -lt 60 ]; do
  i=$((i+1)); sleep 60
  docker ps -q --filter name=a4h | grep -q . || { echo "CONTAINER_EXITED at $i min"; break; }
  st=$(docker exec a4h su - a4hadm -c "sapcontrol -nr 00 -function GetProcessList" 2>/dev/null)
  green=$(printf '%s\n' "$st" | grep -c ', GREEN,')
  other=$(printf '%s\n' "$st" | grep -c ', YELLOW,\|, GRAY,\|, RED,')
  echo "[$i min] green=$green other=$other | $(docker logs a4h 2>&1 | tail -1)"
  [ "$green" -ge 4 ] && [ "$other" -eq 0 ] && { echo READY; break; }
done
# 실행: wsl -d ubuntu-22.04 -- sh -c 'tr -d "\r" < /mnt/c/Users/user/AppData/Local/Temp/sap-wait.sh > /tmp/sap-wait.sh && sh /tmp/sap-wait.sh'
# 결과: [1 min] green=1 other=3 | Worker Processes: starting
#       [2 min] green=4 other=0 | *** Have fun! ***
